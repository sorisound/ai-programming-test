# 성적 CSV 정제와 반별 분석 (analysis)

> 12주차 제출 자료: 워크시트 여섯 장, pytest 화면, 결론 한 문단은 [`제출자료/12주차_실습_제출.pdf`](제출자료/12주차_실습_제출.pdf)에 있습니다.

## ① 무엇을 하나요 (What)

지저분한 성적 CSV를 정제한 뒤, 반별·과목별로 묶어 평균을 냅니다.

- `정제(df)` : 빈 점수, 완전히 같은 행, 0~100 밖 점수를 지우고 반·과목 값의 앞뒤 공백을 없앱니다. 단계마다 남은 행 수를 출력합니다.
- `반별평균(df)` : 반별 개수·평균·중앙값·최댓값 표를 출력하고, 반 이름을 키로 하는 평균을 돌려줍니다.

## ② 왜 만들었나요 (Why)

"어느 반이 더 잘했나"에 답하려고 만들었습니다. 원본에는 점수 999 같은 값이 섞여 있어서, 정제하지 않고 평균을 내면 점수 평균이 100점을 넘습니다.
정제한 뒤에도 반 전체 평균과 과목별 평균이 서로 다른 답을 내서, 둘 다 볼 수 있게 했습니다.

## 데이터

| 항목 | 내용 |
| --- | --- |
| 출처 | 수업 배포 자료 (week12_files). 실습용으로 만든 가상 성적이며 실제 학생 정보가 아닙니다. |
| 파일 | `scores_2026.csv` (UTF-8), `scores_2026_cp949.csv` (같은 내용, CP949 → `encoding="cp949"` 필요), `mini.csv` (손계산 검증용 10행) |
| 행 수 | 원본 114행 → 정제 후 100행 (1반 50 · 2반 50) |
| 열 | 학번(문자) · 이름(문자) · 반(1반/2반) · 과목(프로그래밍/영어/수학) · 점수(0~100 정수) |
| 정제한 것 | 빈 점수 6행 삭제 · 완전히 같은 행 4행 삭제 · 범위 밖 4행 삭제(999 세 개, -5 하나) · 반 공백 2행, 과목 공백 1행 정리 |

**★ 빈 칸은 지웠습니다.** 점수가 빈 6행을 평균으로 채우면 보지 않은 시험 점수를 지어내는 것이고, 채운 값이 반 평균을 그쪽으로 끌고 갑니다. 그래서 채우지 않고 삭제했고, 몇 행이 지워졌는지 단계마다 출력되게 했습니다.

## ⑤ 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `analysis.py` | `정제(df)`, `반별평균(df)`. 직접 실행하면 필터링·그룹화·통계 결과를 출력 |
| `test_analysis.py` | 행 수 보존 2개 · 합계 일치 1개 · 손계산 대조 1개 테스트 |
| `scores_2026.csv` · `scores_2026_cp949.csv` · `mini.csv` | 데이터 (위 「데이터」 참고) |
| `prompts.txt` | 수업에서 받은 프롬프트 원문 |
| `pytest.ini` | `pytest`만 쳐도 `제출자료/`는 빼고 돌리게 하는 설정 |
| `제출자료/` | 12주차 제출 PDF, AI에게 보낸 프롬프트(`responses/prompt_*.txt`)와 받은 응답 원문(`responses/answer_*.md`), 일부러 틀린 pytest 결과 |

## ⑥ 만든 사람 · AI를 어디에 썼는지

- 만든 사람 : 천다민 (학번 2026100234)
- AI를 쓴 곳 : `analysis.py`와 `test_analysis.py`는 Claude Opus 5.5에게 새 대화 하나에서 프롬프트 A~E를 한 단계씩 나눠 시켜 받았고, 코드는 고치지 않았습니다. 사용 예시만 AI가 안내한 대로 `if __name__ == "__main__":` 안에 넣었습니다.
- 내가 직접 한 것 : 데이터 명세서와 빈 칸 처리 결정, 원본 진단, mini.csv 손계산, 합계·스팟 체크 검증, 결론

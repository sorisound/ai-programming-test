# test_analysis.py

이 테스트 파일은 지금까지 만든 `정제`와 `반별평균` 함수가 **`analysis.py`** 파일에 들어 있다고 가정합니다. 파일 이름이 다르다면 `from analysis import ...` 줄을 그 이름에 맞게 고쳐 주세요.

```python
import pandas as pd

from analysis import 정제, 반별평균

# 파일을 맨 위에서 한 번만 읽는다
원본_df = pd.read_csv("scores_2026.csv", encoding="utf-8", dtype={"학번": str})
mini_df = pd.read_csv("mini.csv", encoding="utf-8", dtype={"학번": str})

# 읽은 데이터를 한 번만 정제해 두고 모든 테스트에서 함께 쓴다
깨끗한_df = 정제(원본_df)
깨끗한_mini = 정제(mini_df)


# ① 정제하면 100행이 남는지 확인한다
def test_정제_후_행_수():
    assert len(깨끗한_df) == 100


# ② 정제 후 반 값이 '1반'과 '2반' 두 가지뿐인지 확인한다
def test_반_값_종류():
    assert set(깨끗한_df["반"].unique()) == {"1반", "2반"}


# ③ 반별 점수 합계를 모두 더한 값이 전체 점수 합계와 같은지 확인한다
def test_반별_합계의_합():
    반별_합계 = 깨끗한_df.groupby("반")["점수"].sum()
    assert 반별_합계.sum() == 깨끗한_df["점수"].sum()


# ④ mini.csv를 정제한 뒤 1반 평균이 80.0인지 확인한다
def test_mini_1반_평균():
    평균 = 반별평균(깨끗한_mini)
    assert 평균["1반"] == 80.0
```

## 실행 방법

`scores_2026.csv`, `mini.csv`, `analysis.py`, `test_analysis.py`를 **같은 폴더**에 두고, 그 폴더에서 아래 명령을 실행합니다.

```bash
pytest test_analysis.py -v
```

`-v`를 붙이면 테스트마다 통과(PASSED)했는지 실패(FAILED)했는지 한 줄씩 보여 줍니다. 다른 폴더에서 실행하면 CSV 파일을 찾지 못해 오류가 납니다.

## 설명

- **② `set(...)`으로 비교하는 이유**: `unique()`는 값이 나온 순서대로 돌려줍니다. 그래서 `['2반', '1반']`처럼 순서가 바뀌어 나올 수 있습니다. 집합(`set`)은 순서를 따지지 않으므로 종류만 정확히 비교할 수 있습니다. 또 공백이 남아 `' 1반'` 같은 값이 섞여 있으면 이 테스트가 실패합니다. 그래서 3단계 공백 제거가 잘 되었는지도 함께 확인됩니다.
- **③ 이 테스트가 잡아내는 것**: 보통은 항상 같아야 합니다. 그런데 `반` 값이 비어 있는(NaN) 행이 있으면 `groupby`가 그 행을 빼고 묶습니다. 그러면 반별 합계의 합이 전체 합계보다 작아집니다. 즉, 어느 반에도 속하지 않은 행이 남아 있는지 확인하는 테스트입니다.
- **④ `== 80.0` 비교**: `반별평균`이 이미 소수 둘째 자리까지 반올림해서 돌려주므로 그대로 비교해도 됩니다.

## 참고

- `정제`와 `반별평균`은 안에서 `print`를 합니다. pytest는 테스트가 통과하면 이 출력을 숨기고, 실패했을 때만 보여 줍니다. 출력을 항상 보고 싶다면 `pytest test_analysis.py -v -s`로 실행하세요.

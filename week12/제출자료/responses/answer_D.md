```python
def 반별평균(df):
    # 반으로 묶어 개수·평균·중앙값·최댓값을 한 표로 만든다
    표 = df.groupby("반")["점수"].agg(["count", "mean", "median", "max"])

    # 소수 둘째 자리까지 반올림한다
    표 = 표.round(2)

    # 표를 출력한다
    print(표)

    # 반 이름을 키로 하는 평균값 Series를 반환한다
    return 표["mean"]


# 사용 예시
평균 = 반별평균(깨끗한_df)
print(평균)
print(평균["1반"])
```

## 설명

- **`agg([...])`**: 여러 계산을 한 번에 해서 표로 모아 줍니다. 리스트에 적은 순서대로 열이 만들어집니다.
  - `count`: 점수가 있는 행의 개수
  - `mean`: 평균
  - `median`: 중앙값 (점수를 크기 순으로 세웠을 때 가운데 값)
  - `max`: 최댓값
- **`round(2)`**: 표 전체를 소수 둘째 자리까지 반올림합니다. 개수와 최댓값은 원래 정수라서 값이 바뀌지 않습니다.
- **반환값**: 표에서 `mean` 열만 꺼내 돌려줍니다. 이 Series는 반 이름이 키 역할을 합니다. 그래서 `평균["1반"]`처럼 꺼내 쓸 수 있습니다.

## 출력 모양

```
     count   mean  median  max
반
1반    ...    ...     ...  ...
2반    ...    ...     ...  ...
```

## 딕셔너리로 받고 싶을 때

Series 대신 파이썬 기본 딕셔너리가 필요하면 반환 줄을 이렇게 바꾸면 됩니다.

```python
    # 반 이름을 키로 하는 평균값 딕셔너리를 반환한다
    return 표["mean"].to_dict()
```

이렇게 하면 `{'1반': ..., '2반': ...}` 모양으로 돌려받습니다.

## 주의: 비슷한 이름

앞 단계에서 만든 변수 `반별_평균`(밑줄 있음)과 이 함수 `반별평균`(밑줄 없음)은 이름이 비슷합니다. 하지만 서로 다른 것이니 헷갈리지 않도록 주의하세요. 혹시 변수 이름을 `반별평균`으로 바꿔 쓰면 함수가 덮어써져서 더 이상 호출할 수 없게 됩니다.

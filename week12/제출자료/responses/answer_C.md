```python
# 반별 점수 평균을 구한다
반별_평균 = 깨끗한_df.groupby("반")["점수"].mean()
print(반별_평균)

# 과목과 반 두 기준으로 묶어 점수 평균을 구한다
과목_반별_평균 = 깨끗한_df.groupby(["과목", "반"])["점수"].mean()
print(과목_반별_평균)
```

## 설명

- **`groupby("반")`**: 같은 반끼리 행을 묶습니다. 묶은 뒤 `["점수"]`로 점수 열만 고르고, `.mean()`으로 묶음마다 평균을 냅니다.
- **두 기준으로 묶기**: 기준이 두 개 이상이면 `["과목", "반"]`처럼 **리스트**로 넘깁니다. 앞에 쓴 열이 큰 묶음이 됩니다. 이 코드는 과목별로 먼저 나누고, 그 안에서 반별로 다시 나눕니다.
- **결과 모양**: 두 기준으로 묶으면 결과가 세로로 길게 나옵니다.
  ```
  과목     반
  수학     1반    ...
           2반    ...
  영어     1반    ...
  ```

## 참고: 보기 좋게 출력하기

평균은 소수점이 길게 나올 수 있습니다. `.round(1)`을 붙이면 소수 첫째 자리까지만 보입니다. 또 `.unstack()`을 붙이면 반이 열로 펼쳐져 표처럼 보입니다.

```python
# 소수 첫째 자리까지 반올림하고, 반을 열로 펼쳐 표 모양으로 만든다
print(과목_반별_평균.round(1).unstack())
```

```
반       1반    2반
과목
수학     ...    ...
영어     ...    ...
프로그래밍  ...    ...
```

이 부분은 선택 사항입니다. 과제에서 요구한 결과는 위의 기본 코드만으로 충분합니다.

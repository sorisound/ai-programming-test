```python
# 과목이 '수학'인 행만 남긴다
수학_df = 깨끗한_df[깨끗한_df["과목"] == "수학"]
print("수학 행 수:", len(수학_df))

# (응용) 1반이면서 90점 이상인 행만 남긴다
우수_1반_df = 깨끗한_df[(깨끗한_df["반"] == "1반") & (깨끗한_df["점수"] >= 90)]
print("1반 90점 이상 행 수:", len(우수_1반_df))
```

## 설명

- **`==` 비교**: `깨끗한_df["과목"] == "수학"`은 행마다 True/False를 돌려줍니다. 이것을 `[ ]` 안에 넣으면 True인 행만 남습니다.
- **조건 여러 개 묶기**: 두 조건을 모두 만족해야 할 때는 `and`가 아니라 `&`를 씁니다. 그리고 각 조건을 **반드시 괄호 `( )`로 감싸야** 합니다. 괄호가 없으면 연산 순서가 꼬여서 오류가 납니다.
- **`>= 90`**: "90점 이상"이므로 90점도 포함합니다. 90점을 빼야 한다면 `> 90`으로 바꾸면 됩니다.
- **공백 문제**: 정제 함수의 3단계에서 앞뒤 공백을 이미 지웠습니다. 그래서 `' 수학'` 같은 값이 섞여 있지 않고, `== "수학"`만으로 빠짐없이 걸러집니다.
